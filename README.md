Этот проект предоставляет реализацию кватернионов в Python, включая основные операции над ними и функции для поворота векторов в пространстве.

Структура проекта:
```
1_quaternion/
├── quaternion.py       # Класс Quaternion
├── test_quaternion.py  # Тесты
└── reqirements.txt
```

Операции:
  - Сложение (`+`)
  - Вычитание (`-`)
  - Умножение (`*`)
  - Деление (`/`)
  - Вычисление модуля (`abs`)
  - Сопряжение
  - Обратный кватернион
  - Поворот векторов в пространстве

Запуск:
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите тесты: `pytest test_quaternion.py`
